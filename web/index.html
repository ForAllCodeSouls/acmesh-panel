同步规则

这套规则用于本地挂载目录的自动覆盖：面板签发或续期成功后，把新证书和私钥写到规则匹配到的文件里。规则的「远程主机」栏与主机「自动同步」开关控制本地覆盖成功后是否把对应文件自动推到目标主机；手动远程同步则在「远程同步」页签按目标机器上的证书内容对比进行。写入时先写临时文件再替换，过程中断也不会留下坏文件；证书文件所有人可读写、其他人只读，私钥文件只有面板自己能读写。

匹配方式：先看目录里已有证书的名字或内容，找到对应的文件，再按规则把新内容写进去。下面预设一步创建，也可以用「新建规则」自己配，创建前可点「预览匹配」确认会覆盖哪些文件。

精确归属优先：目标文件名里的域名与面板里某张证书完全同名时，只由那张证书写这个文件；泛域名/子域匹配不会抢写已有独立证书的子域文件，保证文件内容与文件名域名始终一致。

严格按证书实际签发的域名匹配：只认证书里的 CN 和 SAN（含通配符覆盖的同一级子域，*.example.com 只覆盖 sub.example.com）。证书没签的域名不会匹配，例：证书只签 mypython.example.net 时，其它 *.example.net 文件不会被认领。

每条规则不选「远程主机」时只做本地覆盖；选了主机才会把命中文件同步到对应机器。

远程证书目录

像本地挂载目录一样查看选中主机上的证书文件

目录直接读取主机配置里的「远程证书目录」，先选择主机，再点「查看文件」。

文件类型只看文件自身内容：面板通过 SFTP 读取远程文件，能解析出 X.509 证书就标注「证书」并显示它签发的域名，是 PEM 私钥就标注「私钥」；即使面板没签发过这个域名也照样识别。内容读不出的一律显示「文件」，不靠文件名猜。

「证书内容匹配」是另一件事：只有文件内容里的域名与面板已签发证书对得上（精确域名优先，通配 SAN 只覆盖同一级子域），才标「可同步」并能在「立即同步」时用最新证书/私钥覆盖。面板未签发的证书显示「面板未签发此域名」，不会被同步覆盖。列表按名称排序，目录排在最前。

远程主机同步

远程同步只按「证书内容」对比：点击「立即同步」时，面板读取目标机器上证书文件里的 CN/SAN，与面板已签发的证书逐条对比，命中才用最新证书和私钥覆盖目标文件（文件名不变）。未变内容自动跳过，勾选强制同步则全部覆盖。

同步规则、文件名、主机名称都不参与匹配：主机「名称」只是给自己看的备注，不决定任何归属。「同步规则」页签只管本地挂载目录的覆盖；规则的「远程主机」栏与主机「自动同步」开关控制本地同步成功后是否把对应文件自动推到目标主机。主机设置了「负责的域名」时，只覆盖证书内容属于该主机的文件。

把本地同步好的证书文件，通过 SSH 同步到其他主机。支持 SSH 私钥或账号密码认证，凭证加密保存在面板数据库里，不会明文出现在网页或日志中。连接由面板内置的纯 Go SSH 完成，不依赖 ssh / scp 命令。

远程目录必须是绝对路径（如 /etc/ssl/certs），在主机配置里设置；目录不存在时会自动创建。首次连接会记录主机密钥指纹，后续密钥变化会拒绝连接。本地写入与远程同步的结果统一记录在下方「同步记录」里。

修改账号

修改会持久保存，重启后仍生效；所有会话立即失效，需用新账号重新登录。环境变量只在首次启动时用于初始化。

修改密码

密码需至少 12 位且同时包含大写、小写字母与数字；修改会持久保存，重启后仍生效，其它登录会话会立即失效。环境变量只在首次启动时用于初始化。

运行信息

仅切换管理界面的常用文案；证书与配置内容保持原样。

开启后，通过 IP / 端口的 HTTP 直连会被静默断连（等同访问空端口），只能经 HTTPS 反代访问；反代需传递 X-Forwarded-Proto: https。健康检查 /api/health 不受限制。若 HTTPS 也打不开，设置 ACME_PANEL_FORCE_HTTPS=0 后执行 docker compose up -d 即可恢复（restart 不会刷新环境变量）。

导出备份

把面板配置打包成一个 JSON 文件下载保存

包含：DNS 服务商凭证、通知渠道、远程主机（SSH 私钥）、同步规则与同步记录、去重摘要、证书邮箱、自动更新与清理设置。所有凭证都是加密后的密文，备份文件里没有明文私钥或 token。
