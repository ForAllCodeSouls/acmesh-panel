同步规则

面板签发或续期成功后，把新证书和私钥写到下面规则匹配到的文件里。写入时先写临时文件再替换，过程中断也不会留下坏文件；证书文件所有人可读写、其他人只读，私钥文件只有面板自己能读写。

匹配方式：先看目录里已有证书的名字或内容，找到对应的文件，再按规则把新内容写进去。下面预设一步创建，也可以用「新建规则」自己配，创建前可点「预览匹配」确认会覆盖哪些文件。

远程主机同步

远程推送与本地证书同步相互独立：默认只在点「强制同步到远程」时推送；如需每次本地同步后自动推送，请在主机配置里开启「自动推送」。

把本地同步好的证书文件，通过 SSH 推送到其他主机。支持 SSH 私钥或账号密码认证，凭证加密保存在面板数据库里，不会明文出现在网页或日志中。连接由面板内置的纯 Go SSH 完成，不依赖 ssh / scp 命令。

远程目录必须是绝对路径（如 /etc/ssl/certs）；目录不存在时会自动创建。首次连接会记录主机密钥指纹，后续密钥变化会拒绝连接。推送结果同样出现在「最近同步记录」里。
